# Imagem-para-Post

Ferramenta web para recortar, ajustar, comprimir e exportar imagens no formato ideal para posts.

## 🚀 Usar a ferramenta

👉 **[Abrir Imagem-para-Post](https://rios-impassiveis.github.io/imagem-para-post/)**

A ferramenta funciona diretamente no navegador, sem necessidade de instalar programas.

## ✨ Recursos

- 📐 Recorte para **1200 × 628 px** — WordPress / WhatsApp
- 📱 Formato quadrado **1080 × 1080 px** — Instagram
- ⚙️ Dimensões personalizadas
- 🔍 Controle de zoom
- ↔️ Ajuste da posição horizontal e vertical
- 🎨 Escolha da cor de fundo
- 🖼️ Detecção automática da cor das bordas da imagem
- 📦 Exportação em `.WEBP` ou `.JPG`
- 🎚️ Controle de qualidade e compressão
- 📊 Estimativa do tamanho final do arquivo
- 📋 Suporte a colar imagens com `Ctrl+V`
- 🖱️ Arrastar e soltar imagens
- 📱 Interface responsiva

## 🔒 Privacidade

As imagens são processadas **diretamente no navegador**.

Nenhuma imagem é enviada para um servidor para ser processada. O processamento é realizado localmente usando a API Canvas 2D do navegador.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas 2D API

Não utiliza backend ou banco de dados.
